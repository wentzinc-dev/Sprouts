# Sprouts プライバシーポリシー

最終更新日：2026年11月14日

SproutsはWENTZ, K.K.が提供するmacOS向け画像変換アプリです。

## 収集するデータ

Sproutsは、個人情報、利用状況、診断情報、位置情報、連絡先その他のユーザーデータを収集しません。アカウント登録、広告、解析、トラッキング機能もありません。

## ファイルの処理

ユーザーが選択またはドロップした画像、PDF、PSDその他の対応ファイルはMac内で処理されます。入力ファイルや変換結果を外部サーバーへ送信しません。

Sproutsは、ユーザーが選択した保存先へ継続してアクセスするため、macOSのセキュリティスコープ付きブックマークを端末内に保存する場合があります。この情報は端末外へ送信されません。

## 第三者サービス

Sproutsは広告、アクセス解析、クラウド処理などの第三者サービスを使用しません。画像形式の変換に含まれるオープンソースライブラリは、Mac内での処理にのみ使用されます。

## お問い合わせ

本ポリシーまたはSproutsに関するお問い合わせは、[WENTZ Apps共通のお問い合わせフォーム](https://docs.google.com/forms/d/e/1FAIpQLSd3V74ozJ3_UB7zVQASpR711yqdjQlCQbyb2Tw7IwPBomWDOw/viewform?usp=dialog)からご連絡ください。パスワードや機密情報などは送信しないでください。

# Privacy Policy (English)

Last updated: November 14, 2026

Sprouts is a macOS image conversion app provided by WENTZ, K.K.

Sprouts does not collect personal information, usage data, diagnostics, location, contacts, or other user data. It does not include accounts, advertising, analytics, or tracking.

Images, PDFs, PSDs, and other supported files selected or dropped by the user are processed locally on the Mac. Source files and converted output are not uploaded to external servers.

Sprouts may store macOS security-scoped bookmarks locally so it can continue accessing output folders selected by the user. This information never leaves the device.

Sprouts does not use third-party advertising, analytics, or cloud-processing services. Included open-source image-format libraries are used only for local processing.

For questions about this policy or Sprouts, please use the [WENTZ Apps support form](https://docs.google.com/forms/d/e/1FAIpQLSd3V74ozJ3_UB7zVQASpR711yqdjQlCQbyb2Tw7IwPBomWDOw/viewform?usp=dialog). Do not submit passwords, confidential information, or other sensitive data.
